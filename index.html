Shopify backend & checkout

Cart transforms & bundle pricing

Löwenanteil · Shopify Functions

I extended a Cart Transform Function to price upsell bundles. It expands a bundle into its component variants and distributes a configured bundle price across the items. I also added support for a second bundle format alongside the original quantity-based logic.

Checkout payment ordering

HOLY · Colibri Skincare · Rosemary

I built and adjusted Payment Customization Functions to reorder available methods at checkout. For HOLY, I moved PayPal to the first position. Colibri and Rosemary used their own ordering rules.

Checkout UI extensions

Wine in Black · HER ONE

For Wine in Black, I built a rule into a checkout extension that removes a configured app-only discount when the cart lacks the app marker. For HER ONE, I added merchant-editable translations to a checkout block that displays icons with text.

Inventory & fulfillment integrations

CULTIZM · Wine in Black · Weinfürst

I built a Node.js Google Cloud Function for CULTIZM that resolves Shopify variant IDs to inventory items and locations, then updates stock through the GraphQL Admin API. I also added locale-aware carrier tracking links to a Wine in Black order webhook and maintained order webhook API configuration for Weinfürst.

How I build

Give merchants control

I use Shopify section settings, blocks and metafields so teams can move, reuse and edit content. Drink Daily’s merchandising sections and IMMERKIND’s product description are examples.

Build around storefront events

I connect theme interactions to existing data and events. HER ONE’s quiz-to-cart handoff and Precision Food’s variant-aware ingredient gallery show that approach.

Account for the whole journey

I work through responsive media, accessible controls and regional routing. HOLY’s market selector combines a location suggestion, shopper choice and a remembered preference.
