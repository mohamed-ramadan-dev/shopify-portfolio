Feature walkthrough

Giving the merchant control over product descriptions

I made the description a reusable Shopify block and also added a mobile banner video option. The original theme work included the product detail layout and animated collection filters.

  1. Write product-specific content

    The merchant enters a description in a product metafield.

  2. Place the block

    The merchant positions the description block and sets its text size in the theme editor.

  3. Render the product page

    Liquid renders the content in the chosen position when the metafield has a value.
